# Café Milo — Antibes

Site vitrine statique bilingue français / anglais pour le Café Milo, à Antibes. Aucun outil de compilation n'est nécessaire.

## Publier avec GitHub Desktop

1. Téléchargez puis extrayez `cafe-milo-github.zip`.
2. Installez et ouvrez GitHub Desktop, puis connectez-vous à votre compte GitHub.
3. Dans GitHub Desktop, choisissez **File → New repository**. Nommez-le `cafe-milo-antibes`, choisissez un emplacement local et décochez l'initialisation automatique du README.
4. Ouvrez le nouveau dossier du dépôt dans l'Explorateur de fichiers. Copiez-y tous les éléments extraits, notamment `index.html`, `favicon.svg`, `images` et le dossier caché `.github`.
5. Dans GitHub Desktop, saisissez un résumé comme `Ajouter le site Café Milo`, puis cliquez **Commit to main** et **Publish repository**.
6. Dans GitHub, ouvrez **Settings → Pages** et choisissez **GitHub Actions** comme source de publication.
7. La publication démarre automatiquement. Son état apparaît dans l'onglet **Actions** ; l'adresse du site apparaît dans **Settings → Pages** une fois le déploiement terminé.

Avec GitHub Free, Pages est disponible pour un dépôt public. GitHub Pages rend le site accessible au public même si le dépôt est privé sur une formule qui autorise Pages privé. Les prochains commits sur `main` republieront automatiquement le site.
